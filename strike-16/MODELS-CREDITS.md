# DEEP STRIKE s16 — deck model credits

All of these are original Innerscene models released CC0. No attribution is required. Pages:

- Carrier — [Generic unarmed aircraft carrier](https://www.innerscene.com/tools/library/3d-parts/generic-unarmed-aircraft-carrier-d97714b9) — CC0. Nimitz-scale hull, angled deck, catapult tracks, island and mast. File `models/deck/carrier.glb` (textures resized to 1024, meshopt).
- Fighters — [F-15 Eagle fighter jet](https://www.innerscene.com/tools/library/3d-parts/f-15-eagle-fighter-jet-e1d11142) — CC0. Real-scale twin-tail fighter with canopy, gear and nozzles. This airframe's wings do not fold, so the parked jets are wings-spread. File `models/deck/f15.glb` (simplified, textures 1024, meshopt).
- Deck crew — [Low-poly worker, male, T-pose, rigged](https://www.innerscene.com/tools/library/3d-parts/low-poly-character-worker-male-t-pose-rigged-42e268c8) — CC0. Rigged human; jerseys are tinted yellow, green, red, white and purple. The Shooter is this rig, posed in the game. File `models/deck/crew.glb`.
- Tow tractors — [Low-poly farm tractor](https://www.innerscene.com/tools/library/3d-parts/low-poly-farm-tractor-5c3dc680) — CC0. Tinted deck yellow. File `models/deck/tractor.glb` (meshopt).
- Helicopter — [Medium helicopter](https://www.innerscene.com/tools/library/3d-parts/medium-helicopter-5e2a0edd) — CC0. Hovering off the port side. File `models/deck/heli.glb` (simplified, textures 512, meshes joined, meshopt).

Meshopt decoder: meshoptimizer, MIT, vendored from three.js r170 examples.

The player's own jet remains the F-35 already credited in `CREDITS.txt` (Sketchfab, non-commercial). It is not one of the new deck models.
