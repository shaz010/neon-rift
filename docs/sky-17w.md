# Sky photograph, s17 · 17w

The high leg and the valley use one equirectangular photograph as the sky.

- Name: Alps Field
- Author: Andreas Mischok
- Page: https://polyhaven.com/a/alps_field
- Licence: CC0. Poly Haven's licence page is https://polyhaven.com/license. The work is public domain. Attribution is not required.
- Source file: https://dl.polyhaven.org/file/ph-assets/HDRIs/extra/Tonemapped%20JPG/alps_field.jpg (Poly Haven's own tonemapped JPEG, 8192×4096)

The game does not ship that full file. At build time it is resized to:

- `tex/sky/alps-field-4k.jpg` — 4096×2048, desktop and iPad
- `tex/sky/alps-field-2k.jpg` — 2048×1024, phones
- `tex/sky/alps-field-env.jpg` — 1024×512, environment lighting

The photograph is a bright day. Snow sits on the Alpine peaks along the horizon, with high cloud and a clear blue sky. The meadow in the lower half of the photo is faded to the haze colour sampled from the horizon (`#616c76`), and the valley fog uses that same colour so the outer ridges meet the picture.
